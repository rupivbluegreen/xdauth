xdauth

Phishing-resistant cross-device login for headless and air-gapped hosts — without a password, and without the phishing weakness of the OAuth 2.0 Device Authorization Grant.

View on GitHub Download v0.1.0 Read the RFC

The problem

A CLI, an SSH session, or any other non-browser client has three ways to authenticate a human against a modern IdP — and they're all bad.

OptionWhy it fails
ROPCRejected once MFA/Conditional Access is on. Turns your app into a credential-harvesting middleman.
Device code (RFC 8628)Structurally phishable — the code isn't bound to the client, and the consent page shows the victim nothing about who asked. Not theoretical: see Microsoft's Storm-2372 advisory.
CIBAThe right answer on paper, but not offered by most major IdPs, and needs a push-capable authenticator every user may not have.

The idea

Keep the good part of the device-code flow — the user authenticates in a browser on any device, so the host itself needs no internet access — and close the two structural gaps by having the broker own the verification page instead of sending users to the IdP's own device-login screen.

1

PKCE

The client's own code_verifier must match. An attacker who tricks a victim into approving still can't collect the result.

2

Number matching

The browser user types the code shown on the client's terminal. No code, no approval.

3

Requester context

The approval page shows the client's host, IP, and kind before anyone can approve anything.

4

Identity match

The IdP identity must equal the login_hint the client asked for — enforced immediately, before approval is even possible.

Try it

git clone https://github.com/rupivbluegreen/xdauth
cd xdauth
docker compose -f deploy/compose/compose.yaml up --build

Brings up a broker, a mock OIDC provider, and a stock OpenSSH server gated entirely by xdauth — no password, no public key. See docs/ssh-demo.md.

Components

PieceWhat

xdauth-sshdRecommended SSH integration — custom server on golang.org/x/crypto/ssh, prompt delivered live, proven by test.built
